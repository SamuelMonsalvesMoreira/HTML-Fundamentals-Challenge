História dos computadores

Os computadores passaram por várias gerações até chegarem aos dispositivos que usamos atualmente. As primeiras máquinas ocupavam salas inteiras e realizavam cálculos muito mais simples do que um celular moderno.

Com o avanço da tecnologia, os equipamentos ficaram menores, mais rápidos e mais acessíveis. Essa evolução tornou possível o surgimento da internet e, depois, da Web.

A Web conecta documentos por meio de links, permitindo que pessoas naveguem entre diferentes conteúdos.

A internet e a Web não são a mesma coisa: a internet é a infraestrutura de rede, enquanto a Web é um dos serviços que funciona sobre ela.

Como funcionam clientes e servidores?

Quando acessamos um site, o navegador atua como cliente. Ele envia uma solicitação para um computador chamado servidor, que responde com os arquivos necessários para mostrar a página.

Etapas de uma requisição

  1. A pessoa digita um endereço no navegador.
  2. O navegador solicita a página ao servidor.
  3. O servidor localiza os arquivos solicitados.
  4. O navegador recebe e interpreta o conteúdo.

Esse processo costuma acontecer em poucos segundos. O navegador interpreta o HTML e apresenta sua estrutura na tela.

O que é HTML?

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto. Ele é usado para organizar o conteúdo de páginas da Web.

HTML é uma linguagem de programação marcação. Suas tags indicam o papel de cada conteúdo, como títulos, parágrafos, listas e links.

Uma fórmula também pode ser representada com HTML: a água é H2O e 102 é igual a 100.

Estrutura básica

Um documento HTML normalmente possui uma declaração de tipo, uma tag raiz, uma área de configurações e uma área para o conteúdo visível.

  • <html>: envolve todo o documento.
  • <head>: guarda informações sobre a página.
  • <body>: contém tudo o que aparece no navegador.

Tags importantes do HTML

As tags ajudam a criar uma hierarquia clara. O título principal usa <h1>, enquanto os títulos seguintes podem usar níveis de <h2> até <h6>.

Tags pesquisadas para o desafio

  • <abbr>: apresenta o significado de uma abreviação, como DIO.
  • <del>: mostra que um conteúdo foi removido ou corrigido, como em texto antigo.
  • <font>: era usada para alterar a aparência do texto.
